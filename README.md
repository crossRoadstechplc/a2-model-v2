# A2 Investor Simulator

Electric freight corridor financial model with auth-gated access.

## Quick Start

```bash
npm install
cp .env.example .env   # optional; defaults to http://localhost:3000
npm run dev
```
## Documentation

- **DEVELOPER.md** – Environment variables, API base URL, auth flow, onboarding
- **../a2-model-backend/server/API.md** – Backend API reference (source of truth)

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run test` | Run tests |
